Orbit Breakout

Emergency Departure

Fight your way through a spaceship, take down its heavy sentinel, and reach the escape pod.

The game

A third-person sci-fi shooter built by Teddy Kindler with AI assistance. Six encounters take the player through security corridors, cargo, control, a reactor arena and the escape bay.

Two weapons

Start with the ARC-9 blaster, then collect the HELIX-12 plasma repeater before entering the reactor. Each weapon has its own ammunition and reload.

The Bull Sentinel

A solo 2,400-health boss with telegraphed charges, jumpable shockwaves and an overdrive phase at half health. A roar animation and camera close-up introduce the fight.

Enemy awareness

Enemies react to sight and sound, alert nearby squadmates and investigate the player's last known position.

A ship to escape

Industrial corridors, room landmarks, an orbital vista and an open reactor arena lead toward the final escape sequence.

How it was built

Native C++ handles combat, enemy behavior, checkpoint recovery, menus and the boss encounter. Python authoring scripts build and validate the Unreal level. The project combines original environment geometry and audio with licensed character and animation assets, including SciFi Beast06 Bull.

Playing it

This is a native desktop game played through Unreal Engine 5.8. There is no browser demo or current standalone download available here. The complete editable game is available in the private GitHub repository. Repository access requires permission from the owner because it includes licensed source assets.
